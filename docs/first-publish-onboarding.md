# 第一次发布相册

在「我的相册」填写名称并创建相册。创建时可展开「访问选项」设置公开访问或密码保护，默认通过专属链接访问。

添加照片后，第一张处理就绪时即可预览。服务端通过发布检查后，点击「发布相册」打开分享面板。公开相册和密码相册可以直接复制链接，专属链接相册可生成一条 30 天有效的链接。

「空间展示」可选择潮汐、折廊或空间，作为访客从封面进入时的默认 3D 场景。首发时如果还没有场景草稿，发布逻辑会用潮汐建立首个配置版本。已发布相册在重新发布配置后应用所选场景。发布失败后，工作台根据服务端最新状态重试。

流程回归覆盖上传后就绪、版本部分成功后重试、密码保护和私密链接复用。见[首次发布测试](../apps/gallery-admin/e2e/first-publish.spec.ts)和[相册改造设计](superpowers/specs/2026-11-23-album-experience-design.md)。
