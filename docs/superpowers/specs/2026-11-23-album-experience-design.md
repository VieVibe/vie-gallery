# 阳光明媚相册改造

## 产品定位

阳光明媚帮助个人和摄影创作者把一组照片整理成可以发给别人的相册。创作者用照片、封面和顺序表达主题，访客打开链接即可从封面进入，顺着相册浏览，也能直接放大任意一张。

默认操作路径是新建相册、添加照片、预览、发布并分享。创建只需填写名称，自动分配访问地址。新相册默认通过专属链接访问，创建时可以选择公开或加密码。上传完成后，工作台直接显示下一步以及阻碍发布的原因。

## 取舍

| 方向 | 对使用体验的影响 |
| --- | --- |
| 继续完善空间展厅 | 可延续复杂场景的表现力。读者仍需先理解空间控制，创作者仍会遇到场景配置。 |
| 以单张轮播为核心 | 容易上手，适合少量照片。多组照片难以扫读，横竖构图与组照关系也难以表现。 |
| 以封面和连续阅读为核心 | 来访时直接看到作品，可快速浏览整册，也可放大逐张欣赏。空间漫游按需进入。采用此方向。 |

## 需求与交互

- **创建与整理**。相册列表以封面和名称为主。创建表单默认显示名称，地址和访问方式可以展开修改。相册编辑页将照片作为主体，保留批量上传、标题、排序、封面、批量操作和上传失败恢复。
- **发布与分享**。编辑页提供单一发布入口，沿用服务端发布检查。上传批次和处理状态变化及时刷新发布就绪状态。公开与密码相册提供相册链接，私密相册提供生成与复制专属链接。访问权限、历史链接、海报和撤回发布可从分享或相册设置进入。
- **阅读**。优先使用创作者设置的封面，无法读取时尝试相册首张。正文按原排序和长宽比分组，宽幅作品占独立一行。窄屏按顺序逐张展示。所有照片保留完整构图，大图查看器支持键盘、触屏和跨页连续浏览。
- **空间展示**。访客可从相册进入空间漫游，创作者可展开空间设置和使用原有实时配置。主动选择过漫游的访客仍可沿用其浏览偏好。

## 架构与兼容

访客端继续通过现有公开访问状态机获取元数据、照片分页和配置。平面相册的封面、相片编排和图片降级由独立 Vue 组件负责。WebGL 引擎仅在空间模式和实时配置预览挂载，嵌入预览仍以配置草稿为准。大图下载仍使用已授权的配置与现有图片来源。

管理端复用上传、发布、版本、分享和预览的接口。相册首屏从服务端就绪状态派生操作，配置工具由创作者展开时加载。所有者的链接列表返回已生效的短链接，读取时沿用原有凭证。系统沿用现有表结构、访问网址和媒体存储。

## 验收

- 空白相册无需配置空间即可上传，照片就绪后在同一页面发布并打开分享。
- 发布阻断和部分失败清晰可见，重试使用最新状态。
- 桌面和窄屏显示相同的照片顺序，封面与正文可处理竖图、宽幅、缺失尺寸和图片加载失败。
- 普通访客默认路径不请求 WebGL 引擎，旧分享与密码解锁有效，主动进入空间漫游仍能使用原有编排。
